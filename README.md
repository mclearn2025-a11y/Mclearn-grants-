# McLearn Grant Portal

McLearn Media LLC's grant finder and tracker. Pick a project at the top (Speakeasy app, MP music, Church & community media, or add your own) to see its grants, every way the project helps people, a proposal draft builder, and a get-ready checklist.

- Static site: one `index.html`, no build step. Cloudflare serves the repo root as-is.
- Statuses, notes, checklists, added grants and added projects save in the browser you use (on this site). The claude.ai version of the portal saves to a shared tracker instead.
- Grant facts were checked Oct 17, 2026. Deadlines change, so open each grant's link before applying.
